# Socle Angular: demo

Demo application of **Socle**, an industrial-grade Angular 22 starter: zoneless, signals, 13 quality
gates in one command, GitHub, GitLab and Jenkins CI ready.

**See the demo:** https://consigne-studio.github.io/angular-starter-demo/

This repository only contains the production build of the demo. The API is simulated in the browser
and the data is fictitious: your changes disappear on reload.

The full source code, documentation and pipelines are sold on the product page.
